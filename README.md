# Editorial Personal Portfolio — HTML/CSS/JavaScript

A framework-free personal portfolio adapted from the quiet editorial template.

## Open it

Open `index.html` directly in a browser. No npm, React, build process, or local server is required.

## Edit the person in one place

Open `config.js` and change:

- `name`
- `initials`
- `role`
- `discipline`
- `location`
- `availability`
- `email`
- Instagram / LinkedIn links
- homepage statement
- first two project names

## Pages

- `index.html` — Home
- `about.html` — About / approach
- `work.html` — Selected work archive
- `project-field-notes.html` — Project case study 1
- `project-common-ground.html` — Project case study 2
- `experience.html` — Experience / education
- `notes.html` — Short writing / observations
- `contact.html` — Contact details

## Project visuals

The two project pages currently use deliberately minimal abstract CSS plates so the site works without any stock imagery. Replace them later with your own project images if desired.

## Forms and hosting

The site has no backend dependencies. It can be hosted on GitHub Pages, Netlify, Cloudflare Pages, Vercel, or any standard static host.

## Accessibility

The build includes semantic headings, skip links, visible keyboard focus, responsive layouts, and reduced-motion support.
